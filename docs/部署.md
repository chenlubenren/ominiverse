# 部署说明

项目直接运行 Node.js，无需前端编译。安装 Node.js 20 或更新版本，并按根目录 README 下载完整 Git LFS 资源后执行：

```bash
npm ci --omit=dev
npm start
```

默认监听 `127.0.0.1:8910`。Linux 可通过进程环境改变地址：

```bash
HOST=0.0.0.0 PORT=3000 npm start
```

PowerShell 使用：

```powershell
$env:HOST = '0.0.0.0'
$env:PORT = '3000'
npm start
```

公网部署建议由 nginx 提供 HTTPS，Node.js 仅监听本机。示例和操作步骤见[公网运维](公网运维.md)。首页为 `/`，辅助页面为 `/asset-studio` 和 `/station-designs`。反向代理须保留完整请求路径与 Host，并转发根路径下的 API。

## 配置

所有配置均可通过进程环境提供。项目启动时还读取 `.env.local`，但**仅识别** `AHOLO_API_KEY`、`FABLE_API_KEY`、`FABLE_BASE_URL`、`FABLE_MODEL`、`FABLE_ALLOW_MODEL_ALIAS`、`DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL`、`BLENDER_PATH`，且不会覆盖已有进程环境变量。可复制根目录 `.env.example` 后填写所需项目。不要把真实配置提交到仓库。

| 变量 | 默认值或作用 |
| --- | --- |
| `HOST`、`PORT` | `127.0.0.1`、`8910`；端口也兼容 `ACCESS_PORT` |
| `MODEL_LIBRARY_ROOT` | 可选家具库路径，默认 `assets/furniture` |
| `OPENAI_API_KEY`、`ACCESS_AI_MODEL` | 可选行程智能解析；默认模型 `gpt-5.6` |
| `DEEPSEEK_API_KEY`、`DEEPSEEK_MODEL` | 可选事件及机器人智能解析；默认模型 `deepseek-flash` |
| `FABLE_API_KEY`、`FABLE_BASE_URL`、`FABLE_MODEL` | 可选兼容接口的机器人智能定制；地址需为 HTTPS |
| `FABLE_ALLOW_MODEL_ALIAS` | 仅在已确认网关模型映射时设为 `1` |
| `LUX3D_CN_API_KEY`、`LUX3D_ALLOW_BILLABLE` | 旧模型生成流程；部分入口需显式允许计费 |
| `BLENDER_PATH` | Blender 可执行文件的完整路径；未设置时自动探测 |
| `CHROME_PATH` | 可选浏览器路径，用于需要渲染参考图的角色生成流程 |
| `ACCESS_PYTHON` | 可选 USDZ 转换 Python 解释器路径 |

`HOST`、`PORT`、`OPENAI_API_KEY`、`ACCESS_AI_MODEL`、`MODEL_LIBRARY_ROOT`、`CHROME_PATH`、`ACCESS_PYTHON`、`LUX3D_CN_API_KEY` 和 `LUX3D_ALLOW_BILLABLE` 须通过进程环境或 systemd `EnvironmentFile` 设置，写入 `.env.local` 不会生效。

基础场景与已有模型不依赖云端凭据。新“机器人库与生成”在生成窗口中要求用户输入自己的模型生成服务 API Key，不会自动使用旧角色接口的环境密钥。关闭窗口会清空输入；任务文件不保存该 Key。真实生成依赖上游账号权限，并可能计费。

## 可选依赖

普通页面展示无需服务器浏览器或 Python。

新机器人外形生成需要 Blender，以及完整的 `assets/robot-templates/crocodile/` 模板。设置 `BLENDER_PATH` 后重启服务。处理脚本使用 Blender 自带 Python；升级 Blender 后应验证模型绑定和动作处理。

需要生成角色参考图时安装 Chromium：

```bash
npx playwright install --with-deps chromium
```

Linux 上启用 USDZ 转换时：

```bash
python3 -m venv .runtime/python-linux
.runtime/python-linux/bin/python -m pip install -r requirements-usd.txt
```

USDZ 转换、旧家具生成和批量角色生成保留本机来源限制。公网使用这些入口会受限。新机器人库接口要求同站点请求与浏览器 Cookie；事件接口支持当前站点来源。新增对外管理或计费能力前，应配置适合部署场景的身份、权限及额度控制。

## 文件与数据

完整发布需包含根目录 HTML/CSS、`server.cjs`、`package.json`、`package-lock.json`、`requirements-usd.txt`，以及 `js/`、`assets/` 和 `scripts/`。模型、纹理、视频、WASM 必须是 Git LFS 下载后的实际文件。使用锁文件执行 `npm ci`，无需复制其他机器的 `node_modules/`。

`.runtime/robot-library/` 保存任务、预览与入库模型，`.cache/` 保存缓存。生产部署应把两者指向独立持久化目录。旧角色生成功能还可能写入 `assets/characters/imported/`；若启用该功能，需单独配置权限和数据备份。

运行目录、用户生成内容、真实 `.env*`、密钥、证书、日志和备份不属于公开发布内容。当前任务状态包含进程内状态，应使用单个 Node.js 实例；版本切换应安排在生成任务空闲时进行。

## 启动检查

```bash
curl -fsS http://127.0.0.1:8910/__access_lab_health__
```

健康接口仅用于本机运维，nginx 示例对公网隐藏此路径。随后在浏览器确认办公楼、机器人库、空间站及影片可加载。云端功能需要各自的有效配置；普通健康检查不提交生成任务。
